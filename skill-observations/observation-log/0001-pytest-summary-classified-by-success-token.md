**Issue:** При переносе 81 тест-файла результаты прогона каждого файла фильтровались через grep -v "passed in". Строка итога pytest «1 failed, 14 passed in 0.2s» тоже содержит «passed in», поэтому файлы с частичными падениями ушли в «прошедшие». Вскрылось только на полном прогоне (34 падения), до вывода пользователю.

**Suggested improvement:** В verify-before-done добавить правило: итог тестов классифицируется по наличию «failed|error» (или по коду возврата pytest), а не по наличию слова успеха.

**Principle:** Классифицируй итог по признаку провала, а не по признаку успеха: сводка смешанного результата содержит оба слова, и фильтр по слову успеха пропускает её как успех.
