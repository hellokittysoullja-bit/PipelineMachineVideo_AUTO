# Faceless YouTube Pipeline — операционная система для Claude Code

Готовый «мозг» для автоматического производства длинных faceless-роликов (закадровый голос + медиаряд, без лица в кадре) силами **Claude Code**. Одна команда — `Новый ролик: [ТЕМА]` — и система сама делает анализ конкурентов, сценарий, подбор медиа и финальную сборку mp4.

Это НЕ программа с кнопкой. Это `CLAUDE.md` (правила) + реальные рабочие скрипты в `scripts/` (уже готовые `.py`-файлы, проверены `py_compile`) + конфиг + bootstrap: Claude Code разворачивает у тебя тот же пайплайн и ведёт производство.

---

## Что внутри

| Файл/папка | Назначение |
|---|---|
| `CLAUDE.md` | Ядро. Все правила: анализ конкурентов, написание сценария, контроль длины, генерация медиа, сборка. Обезличенный, без чужих ключей. |
| `scripts/` | Готовые Python-скрипты: `pipeline_smart.py` (сборка по паузам), `assemble.py` (сборка по слотам + динамичный хук), `stock_fetch_multisource.py` (мультисток Pexels/Pixabay/Unsplash), `fix_pauses.py` (подрезка длинных пауз TTS), `wordcount.py` (контроль длины сценария). |
| `config.example.env` | Шаблон ключей. Копируешь в `.env`, вписываешь СВОИ. |
| `bootstrap.ps1` / `bootstrap.sh` | Автоустановка: ffmpeg, Python-venv, зависимости, папки. Claude запускает сам. |
| `requirements.txt` | Python-зависимости. |
| `Dockerfile` | Воспроизводимое headless-ядро сборки видео (ffmpeg + скрипты). |
| `.github/workflows/tests.yml` | CI: вся суита с ffmpeg на каждый пуш; Windows и ML-прогоны (torch/CLIP) — по расписанию. Ключи не нужны, ничего не публикует. |

## Быстрый старт

1. **Установи Claude Code** (CLI от Anthropic) и открой им эту папку.
2. **Скажи Claude:** «Прочитай CLAUDE.md и выполни первичную настройку». Он запустит `bootstrap` (поставит ffmpeg, создаст venv, зависимости, папки) — скрипты уже на месте в `scripts/`, распаковывать ничего не нужно.
3. **Заполни `.env`** своими ключами (см. ниже).
4. **Настрой канал:** скажи «Заведи CHANNEL.md под нишу [твоя ниша]» — Claude проведёт анализ ниши и создаст файл идентичности канала.
5. **Производство:** `Новый ролик: [ТЕМА]` — дальше по протоколу.

## Что нужно иметь (свои аккаунты и ключи)

Продукт не содержит чужих ключей — всё на твоих аккаунтах:

**Обязательно:**
- **Claude Code** (подписка/API Anthropic) — оркестратор.
- **FFmpeg** — ставится автоматически bootstrap-скриптом.
- **ElevenLabs** (или другой TTS) — озвучка. Ключ + Voice ID → `.env`.
- **Pexels / Pixabay / Unsplash** — бесплатный сток. Ключи → `.env`.

**Опционально (усиливают, но не критичны):**
- **NexLev / vidIQ** — аналитика ниш (подключаются как MCP-коннекторы в Claude Code).
- **Grok Imagine (SuperGrok) / Google Flow** — AI-картинки через браузер (Claude-in-Chrome). Нужна своя подписка/сессия. Оба источника иногда недоступны (гео-блок Flow вне поддерживаемых стран, периодические зависания режима «Изображение» у Grok) — тогда пайплайн падает на честный сток без остановки процесса.
- **Fast Gen AI** — AI-картинки (ручной интерфейс).
- **Gemini API** — разгрузка токенов на анализе.

Каждый сервис — по правилам самого сервиса и на твою ответственность. В РФ для части сервисов и Claude Code нужен VPN.

## Философия

- **Данные, не вкусовщина.** Ни один сценарий не пишется без анализа реально выстреливших конкурентов.
- **Контроль длины = контроль денег.** Обязательный подсчёт слов перед платной озвучкой (`scripts/wordcount.py`).
- **Живой человеческий текст** для озвучки с первого черновика.
- **Только честный/свой визуал** — сток по лицензии + AI-реконструкции, никаких чужих клипов (Content ID).
- **Динамичный хук.** Открывающие 90-120 секунд ролика режутся на уровне предложений с индивидуальной длительностью (не плоским слотом, как тело) — иначе хук либо проглатывается, либо рвётся по темпу.

Подробности — в `CLAUDE.md`.
