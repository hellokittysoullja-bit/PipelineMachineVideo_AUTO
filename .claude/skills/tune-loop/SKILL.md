# Tune loop

Идея — `autoresearch` Карпати (`program.md`): агент правит ОДНО место,
меряет одну метрику, коммит остаётся при улучшении и откатывается при
ухудшении, всё пишется в журнал. Здесь она дополнена защитами, которых у
оригинала нет: в этом репозитории уже дважды записано, что порог,
подобранный на маленьком наборе, — подгонка под шум.

## Когда можно

Все пять условий сразу, иначе цикл не запускать:

1. Метрика **локальная и бесплатная** (`scripts/golden_set_eval.py`,
   `shot_brief_eval.py`, `level_regression.py`, `wordcount.py`). Ни одного
   платного вызова: TTS, судья на шлюзе, генерация, платные стоки.
2. Есть **канарейка**: без ответа модели скрипт падает, а не печатает числа
   (как у золотого набора).
3. Задан **один файл/одна константа** для правки на итерацию.
4. Есть **пол**: базовая линия (`docs/quality/golden_set_baseline.json`),
   ниже которой ни одна ось не должна опускаться.
5. Владелец явно попросил цикл.

## Цикл

```
0. Базовый замер (полный, дважды — проверить детерминизм; разница = шум).
1. Гипотеза одной строкой (ПОЧЕМУ должно стать лучше — не просто «попробую»).
2. Одна правка в одном месте. Коммит в РАБОЧЕЙ ветке не делать — правка
   лежит в рабочем дереве, откат = `git checkout -- <файл>`.
3. Снести __pycache__, полный замер.
4. Решение по ВСЕМ осям, не по одной:
   - keep    — ни одна ось не хуже, хотя бы одна лучше сверх шума;
   - discard — иначе, откатить;
   - crash   — запись в журнал, откатить, к этой идее не возвращаться.
5. Строка в журнал → следующая итерация.
```

**Простота выше цифры:** улучшение на шум, полученное усложнением, — discard;
равный результат при удалении кода — keep (принцип оригинала).

## Журнал

`docs/quality/tune_loop/<дата>_<тема>.tsv`, колонки:
`iter | файл:строка | гипотеза | метрики до | метрики после | статус | заметка`.
Журнал — часть результата: без него итог не принимается.

## Ограничители (то, чего нет в оригинале)

- **Не «никогда не останавливайся».** Лимит итераций задаёт владелец (по
  умолчанию 10). Стоп раньше: 3 discard подряд по одной гипотезе, любое
  нарушение пола, неповторяемый замер (шум больше эффекта).
- **Переобучение.** Улучшение принимается только если оно подтверждено на
  данных, которые НЕ участвовали в подборе (второй эпизод/срез). Если такого
  среза нет — итог помечается «не подтверждено вне выборки», порог не
  вносится в код без слова владельца. Разметка золотого набора — 40 кадров:
  сдвиг порога по одному-двум кадрам — шум.
- **Не двигать пороги гейтов вслепую**: у них задокументированные границы
  безопасного окна (`NEGATIVE_VETO_MARGIN`, `CLIP_RELEVANCE_THRESHOLD`).
  Идти дальше окна = сначала перемерить границу, потом менять.
- Творческие оси (цвет, звук на слух, «красиво») циклом не настраиваются —
  их вердикт за владельцем (Шаг 7.5).

## Итог

Что менялось, метрики до/после числами, что подтверждено вне выборки, что
нет, журнал. Без слова «улучшено» без числа.
