# DOODLE EXPLAINER — генератор роликов-объяснялок с рисованными кадрами

Вход — тема. Выход — `final.mp4` + `final.srt`: закадровый голос и на каждую фразу свой рисованный кадр (человечки, схемы, стрелки, короткие русские подписи), как у каналов вроде PinqoChannel.

Отпочкован от PipelineMachineVideo_AUTO (faceless-документалки на стоке). Оттуда взяты без изменений: разбор сценария (`script_parser.py`), счётчик длины (`wordcount.py`), озвучка Lumean (`lumean_tts.py`), подрезка пауз (`fix_pauses.py`), шлюз моделей (`llm_gateway.py`, `source_health.py`). Весь поиск по стокам и музеям здесь не нужен: каждый кадр рисуется.

- **CLAUDE.md** — механика. **CHANNEL.md** — канал: ниша, аудитория, длина T, герой, голос, контент-план.
- **channel_profile.json** — стиль рисунка, описание героя, размер картинок. Код читает его, а не литералы.
- **Ключи только в `.env`** (шаблон `config.example.env`).

## Установка
```
python -m venv .venv && .venv/bin/pip install -r requirements.txt   # Windows: .venv\Scripts\pip
```
FFmpeg обязателен (Windows `winget install Gyan.FFmpeg`, Linux `apt install ffmpeg`, macOS `brew install ffmpeg`).
`cp config.example.env .env`, вписать ключи. Модель картинок выбрать по каталогу: `python scripts/list_models.py image`.

## Протокол «Новый ролик: [ТЕМА]»
1. **Анализ конкурентов** (обязателен): 5+ выстреливших роликов ниши, приоритет — малые каналы со взлётом ×5-10 к медиане. Разбор: название, превью, первые 60 с, приёмы удержания, типы кадров.
2. **Название + превью** до хука.
3. **Сценарий** `videos/NN_тема/script.txt` поблочно, сразу живым стилем (ниже). Длина: `python scripts/wordcount.py script.txt T` — 125 слов/мин, отчёт «Слов: X. Расчётная длительность: Y мин.» до озвучки.
4. **Кадры:** `python scripts/make_video.py videos/NN_тема --minutes T` — план кадров, затем цена картинок; генерация только с `--confirm-spend`.
5. **Озвучка:** `audio.mp3` в папку ролика или `--tts` (Lumean, платно).
6. **Сборка** — та же команда, продолжает с готового.
7. **Проверка глазами** (обязательна): контактный лист кадров, `media_plan/frames_report.json` — кадры со статусом `text_mismatch`/`unchecked`/`failed` смотреть в первую очередь.
Финал — одна строка «Готово. Файл: [путь]».

## Как устроен кадр
Один блок между `[pause]` = один кадр (как в исходном пайплайне). `frame_planner.py` на каждую фразу выбирает:
- `scene` — рисунок без текста (~45%);
- `caption` — рисунок + одна крупная подпись до 4 слов, «ЖИВ. ПОЛНОСТЬЮ.» (~25%);
- `diagram` — пирамида, стрелки, список на доске, сравнение, 2-6 подписей (~30%).

Плюс: есть ли в кадре сквозной герой, фон (white/paper/painted), русские подписи дословно, английское описание картинки. Бриф автора `[shot:...]` в сценарии главнее модели. Сбой главы или непрошедшая проверку строка → запасной кадр-сцена без текста (слот не пустеет). Кэш по главам: правка одной главы не перепланирует ролик.

`frame_generator.py` рисует кадр моделью `IMAGE_MODEL`, затем `TEXT_CHECK_MODEL` читает текст на картинке, и код сверяет буквы **точно** (без пунктуации, Ё=Е). Похожесть не засчитывается: «ПОЛНОСТЮ» вместо «ПОЛНОСТЬЮ» — брак. Не совпало — ещё попытка (`IMAGE_MAX_ATTEMPTS`), не прошла ни одна — лучший кадр остаётся со статусом `text_mismatch`, код возврата 2. Сцена проверяется на обратное: букв быть не должно.

`assemble_frames.py`: старт кадра — начало фразы по посимвольному alignment озвучки (с пересчётом через `pause_cuts.json`), без alignment — оценка по буквам (в отчёте `source: estimate`). Кадр вписывается в 16:9 целиком, поля — размытая копия (подписи у края не режутся). Медленный наезд/отъезд 5% на всю длину клипа (зум от `on/frames`, не инкрементом). Жёсткие резы по кадровой сетке с переносом ошибки округления. Музыка из `assets/music/` — уровень по замеру громкости (на 18 LU тише голоса) + приглушение под голос, итог -14 LUFS. Недостающий кадр заменяется соседним и попадает в отчёт.

## Деньги
Сильная модель картинок платная, кадров на ролик ~100-250. Перед генерацией печатается верхняя граница цены (кадры × попытки × цена из каталога шлюза). Без `--confirm-spend` генерация не начинается, без `IMAGE_MAX_SPEND` платная модель не запускается. Готовые картинки и прочитанный текст кэшируются: перезапуск не платит. Озвучка платная, только по `--tts`.

## Сценарий: стиль
- Коротко: 5-12 слов, разговорно, на «ты». Без приветствий, «подпишись», канцелярита и «учёные доказали» без имени.
- Живой стиль с первого черновика: маркеры «если честно», «представь», рваный ритм, фразы с «И»/«Но»/«А».
- Анти-ИИ: одна и та же риторическая форма («Не X. А Y», афоризм-пара, нумерованная тройка) не чаще двух раз за сценарий.
- Хук (первые 90 с) — пять рычагов: узнавание себя, вопрос с ответом «да», контринтуитив, якорь-авторитет в первые 10 с, петля-обещание.
- Фактчек: каждое имя, дата и число проверять; легенды — «по одной из версий».
- **Под кадры:** `[pause]` ставить там, где меняется картинка, — примерно каждые 1-2 предложения (8-15 с). Длинный блок без `[pause]` — один кадр на 30 с, зритель уходит.
- Теги TTS: `[energetic]` (хук, один раз), `[pause]`, `[short pause]`, `[slowly]`, `[emphasis]`. Нельзя: `[long pause]`, `[laugh]`, `[sigh]`, `[whisper]`.
- Формат `script.txt`: `=== METADATA ===` (TITLE:), `=== HOOK ===`, `=== BLOCK N: Название ===`, `=== FINAL ===`.

## Честные пределы
- Модель картинок и шлюз в контейнере разработки не проверены живым вызовом (ключей там нет). Проверено тестами с поддельным шлюзом; первый ролик — сначала `--only 1,2,3` на трёх кадрах.
- Герой держится только описанием в каждом промпте. Референс-картинка (`assets/mascot/mascot.png`) пока не передаётся: нужна поддержка `/images/edits` на шлюзе, это следующий шаг.
- Проверка подписей зависит от того, как модель со зрением читает рукописные буквы; её ошибка чтения даёт лишнюю попытку, а не брак на экране.
