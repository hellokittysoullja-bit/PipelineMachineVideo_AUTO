# DOODLE EXPLAINER — генератор роликов-объяснялок с рисованными кадрами

Вход — тема. Выход — `final.mp4` + `subtitles.srt` + `chapters.txt`: закадровый голос и на каждую фразу свой рисованный кадр (человечки, схемы, стрелки, короткие русские подписи), как у каналов вроде PinqoChannel.

**Отпочкован от PipelineMachineVideo_AUTO и стоит на его коде, а не на переписанном.** Всё, что подходит рисованному кадру, перенесено дословно; своё написано только там, где природа кадра другая (кадр рисуется, а не ищется). Замеры, найденные баги и обоснования порогов живут в комментариях перенесённого кода — там и читать.

- **CLAUDE.md** — механика. **CHANNEL.md** — канал (ниша, аудитория, T, герой, голос, контент-план).
- **channel_profile.json** — стиль рисунка, герой, размер кадра. Код читает его, а не литералы.
- **Ключи только в `.env`** (шаблон `config.example.env`). Правила коммуникации, дисциплина расходов, фактчек, стиль текста — как в исходном CLAUDE.md, коротко ниже.

## Что откуда
| слой | модуль | происхождение |
|---|---|---|
| разбор сценария, длина, озвучка Lumean, паузы | `script_parser`, `wordcount`, `lumean_tts`, `fix_pauses` | старый, без изменений |
| паспорт мира эпизода | `world_card` | старый, без изменений |
| спецификация кадра (главное, утверждения must/should) | `frame_planner` + `stock_query_planner.SPEC_PROMPT` | правила дословно из старого v3; своё — описание рисунка |
| судья (сетка, проверка по утверждениям, мир, «лучший как кадр фильма», проверка зрения) | `shot_judge` | старый, без изменений |
| генерация, проверка русских подписей | `frame_generator` | своё: варианты локальной моделью + точная сверка букв |
| тайминг PHRASE LOCK, камера, Ken Burns, переходы, звук, мастеринг, субтитры, главы | `render_core` | дословные функции `pipeline_smart.py`, отобранные по дереву ссылок |
| язык камеры, SFX-режиссёр, атмосфера, библиотека звуков | `camera_language`, `sfx_plan`, `ambience_plan`, `sound_library` | старые, без изменений |
| Speech Director, синхронизация секций, Pause Intelligence | `speech_planner`, `speech_validator`, `section_sync`, `pause_intelligence` | старые, импорт `pipeline_smart` -> `render_core` |
| замер тайминга и отчёт по готовому файлу | `verify_timing`, `segment_report` | старые |
| сборка | `assemble_frames` | своё: связывает `render_core` в порядке старого `main()` |

**Сознательные отличия от старого (и почему):**
- `FILM_LOOK=0` — тёмный киношный грейд `film_look()` выключен: белый лист дудла он делает серым с тёмными углами. `FILM_LOOK=1` возвращает его байт-в-байт.
- `ASPECT_FIT_MIN_RATIO` = 16:9 (было 4:3): кадр уже 16:9 вписывается целиком, у схемы подписи стоят у края.
- Схема и кадр с подписью идут спокойным движением (`micro_drift`), сцены — языком камеры по стадии рассказа.
- `cg_veto=False` в судье: канал рисованный по замыслу, «мультфильм» — не брак.
- Движение (`motion`) из утверждений снимается: рисунок статичен.

## Установка
```
python -m venv .venv && .venv/bin/pip install -r requirements.txt   # Windows: .venv\Scripts\pip
```
FFmpeg обязателен. `cp config.example.env .env`, вписать ключи. Локальная модель картинок — через ComfyUI (`assets/comfyui/README.md`) или любой OpenAI-совместимый сервер (`IMAGE_BACKEND`).

## Протокол «Новый ролик: [ТЕМА]»
1. **Анализ конкурентов** (обязателен): 5+ выстреливших роликов ниши, приоритет — малые каналы со взлётом ×5-10 к медиане; 10-пунктный разбор, медиана-шаблон.
2. **Название + превью** до хука.
3. **Сценарий** `videos/NN_тема/script.txt` поблочно, сразу живым стилем. `python scripts/wordcount.py script.txt T` → «Слов: X. Расчётная длительность: Y мин.» до озвучки.
4. **Всё остальное одной командой:** `python scripts/make_video.py videos/NN_тема --minutes T [--tts]` — паспорт мира и план кадров → кадры (варианты, буквы, судья) → озвучка (или ваш `audio.mp3`) → карта секций → паузы → сборка → замер тайминга → отчёт.
5. **Проверка глазами обязательна** (скиллы `deep-audit`, `av-ground-truth-check`): `media_plan/frames_report.json` (статусы, что прочитано на кадре, оценки судьи), `media_plan/timing_verification.json`, сам `final.mp4`. «Отчёты чистые» ≠ «ролик хороший».
Финал — одна строка «Готово. Файл: [путь]».

## Кадр: как выбирается
- Один блок между `[pause]` = один кадр. `[pause]` ставить там, где меняется картинка — каждые 1-2 предложения (8-15 с).
- Планировщик на фразу пишет спецификацию старого образца (focus, core, subject, claims must/should) и рисунок: `scene` (без текста) / `caption` (одна подпись до 4 слов) / `diagram` (2-6 подписей), русские подписи дословно, английское описание (главное первым), герой, фон. Бриф автора `[shot:...]` главнее модели.
- Генератор рисует `IMAGE_VARIANTS` вариантов (локально бесплатно — по умолчанию 3). Модель со зрением читает текст на каждом; код сверяет буквы **точно** (Ё=Е, без пунктуации). «ПОЛНОСТЮ» вместо «ПОЛНОСТЬЮ» — брак.
- Сетка судьи → проверка лучших по утверждениям и миру → вектор `claims_vector` → при ничьей `rank_look`. Не годен ни один — ещё раунд (`IMAGE_ROUNDS`). Не годен и после — `rejected`: на экран не идёт, время отдаётся соседнему проверенному кадру («ни карточек, ни повторов», решение владельца в старом генераторе).
- Промпт картинки: главное первым, стиль коротким хвостом в конце (урок старого `shot_generator`: длинный стиль впереди съедал предмет).

## Деньги
Локальная модель картинок бесплатна. Платно: планировщик и паспорт мира (DeepSeek, копейки), судья и чтение подписей (Qwen 3.7 Plus; потолок `SHOT_JUDGE_MAX_SPEND`), озвучка (`--tts`). Платная модель картинок (`IMAGE_BACKEND=gateway`) — только с `--confirm-spend` и потолком `IMAGE_MAX_SPEND`, цена печатается до вызова. Всё кэшируется: перезапуск не платит.

## Сценарий: стиль (из исходного CLAUDE.md)
- 5-12 слов, разговорно, на «ты». Без приветствий, «подпишись», канцелярита, «учёные доказали» без имени, паразитов («важно понимать» в любой форме).
- Живой стиль с первого черновика; анти-ИИ: одна риторическая форма («Не X. А Y», афоризм-пара, нумерованная тройка) не чаще двух раз за сценарий.
- Хук (90 с) — пять рычагов: узнавание себя, вопрос с ответом «да», контринтуитив, якорь-авторитет в первые 10 с, петля-обещание.
- Фактчек каждого имени, даты, числа; легенды — «по одной из версий».
- Теги TTS: `[energetic]` (хук, 1 раз), `[pause]`, `[short pause]`, `[slowly]`, `[emphasis]`. Нельзя: `[long pause]`, `[laugh]`, `[sigh]`, `[whisper]`.
- Формат: `=== METADATA ===` (TITLE:), `=== HOOK ===`, `=== BLOCK N: Название ===`, `=== FINAL ===`.

## Честные пределы
- **Живьём не проверено:** локальная модель картинок, судья и чтение подписей на рисованных кадрах, планировщик с новым описанием рисунка — в контейнере разработки нет ни видеокарты, ни ключей. Проверено тестами (подделки шлюза и модели) и сквозной сборкой на синтетике.
- **Судья откалиброван на документальной фотосъёмке** (эп.94 старого канала). На дудлах его пороги и вопросы не мерились — первый ролик размечать глазами и сравнить.
- **Шаблон ComfyUI** (`assets/comfyui/qwen_image_template_api.json`) составлен по стандартному графу и не запускался; надёжнее экспортировать свой.
- **Модель картинок выбирать замером** на 10-15 кадрах реального плана (доля кадров с верными буквами + судья), а не по обзорам.
- **Герой держится только описанием в промпте;** референс-картинка пока не подаётся (нужна модель/граф с редактированием по образцу).
- **Замер тайминга на диссолве:** на границе секции старый план ставит диссолв ~0.42 с от начала фразы; измеритель видит пик посреди диссолва и пишет дрейф до ~0.4 с — известный предел метода, а не рассинхрон.
- Из тестов старого репозитория перенесены 800+ проверок перенесённого кода; тесты стокового подбора и проводки старого `main()` не перенесены (кода нет), проводка нового сборщика — `tests/test_assemble.py`.
