# DOODLE EXPLAINER — генератор роликов-объяснялок с рисованными кадрами

Вход — тема. Выход — `final.mp4` + `subtitles.srt` + `chapters.txt`: закадровый голос и на каждую фразу свой рисованный кадр (человечки, схемы, стрелки, короткие русские подписи), как у каналов вроде PinqoChannel.

**Отпочкован от PipelineMachineVideo_AUTO и стоит на его коде, а не на переписанном.** Всё, что подходит рисованному кадру, перенесено дословно; своё написано только там, где природа кадра другая (кадр рисуется, а не ищется). Замеры, найденные баги и обоснования порогов живут в комментариях перенесённого кода — там и читать.

- **CLAUDE.md** — механика. **CHANNEL.md** — канал (ниша, аудитория, T, герой, голос, контент-план).
- **channel_profile.json** — стиль рисунка, герой, размер кадра. Код читает его, а не литералы.
- **Ключи только в `.env`** (шаблон `config.example.env`). Правила коммуникации, дисциплина расходов, фактчек, стиль текста — как в исходном CLAUDE.md, коротко ниже.

## Что откуда (после аудита 30.09: взято только то, у чего нет минусов для рисованного ролика)
| слой | модуль | происхождение |
|---|---|---|
| разбор сценария, длина, озвучка Lumean, подрезка пауз | `script_parser`, `wordcount`, `lumean_tts`, `fix_pauses` | старый, без изменений (из разбора сценария убран стоковый разбор запросов) |
| спецификация кадра (главное, утверждения must/should) | `frame_planner` | правила и разбор ответа — дословно из старого `stock_query_planner` v3, вшиты; своё — описание рисунка |
| судья (сетка вариантов, проверка по утверждениям, «лучший как кадр фильма», проверка зрения) | `shot_judge` | старый, без изменений |
| генерация кадра (без единой буквы) | `frame_generator` | своё |
| русские подписи — кодом | `labels` | своё: Shantell Sans ExtraBold, запасной Balsamiq Sans (оба OFL), без обводки |
| PHRASE LOCK, голос, музыка по замеру, loudnorm + лимитер, проверка звука, субтитры, главы | `render_core` | дословные функции `pipeline_smart.py` (1 тыс. строк из 19 тыс.) |
| замер тайминга по готовому файлу | `verify_timing` | старый, без изменений |
| картинка: вписывание 16:9, медленный наезд, жёсткие резы | `assemble_frames` | своё, нарочно простое |

**Что из старого сознательно НЕ взято и почему** (аудит 30.09, по прямому вопросу владельца): стоковый/музейный подбор, каскад, полка, паспорт эпохи и культуры (`world_card`), язык камеры и режимы движения, переходы-диссолвы, тёмный киношный грейд, зерно, SFX-режиссёр, атмосферы и библиотека звуков (средневековые места), процедурная музыка-дрон, режиссёр речи (`speech_planner`/`validator`/`generate`, `pause_intelligence`, `stress_placement`), синхронизация секций, отчёты сегментов, реестр из 50 флагов. Для рисованной объяснялки это не улучшение, а поверхность для багов. Цифра: переходы старого генератора давали на границе секций сдвиг картинки до 0.4 с от начала фразы, жёсткие резы — не больше полукадра (замер `verify_timing` на одном и том же ролике).

## Установка
```
python -m venv .venv && .venv/bin/pip install -r requirements.txt   # Windows: .venv\Scripts\pip
```
FFmpeg обязателен. `cp config.example.env .env`, вписать ключи. Локальная модель картинок — через ComfyUI (`assets/comfyui/README.md`) или любой OpenAI-совместимый сервер (`IMAGE_BACKEND`).

## Протокол «Новый ролик: [ТЕМА]»
1. **Анализ конкурентов** (обязателен): 5+ выстреливших роликов ниши, приоритет — малые каналы со взлётом ×5-10 к медиане; 10-пунктный разбор, медиана-шаблон.
2. **Название + превью** до хука.
3. **Сценарий** `videos/NN_тема/script.txt` поблочно, сразу живым стилем. `python scripts/wordcount.py script.txt T` → «Слов: X. Расчётная длительность: Y мин.» до озвучки.
4. **Всё остальное одной командой:** `python scripts/make_video.py videos/NN_тема --minutes T [--tts]` — план кадров → кадры (варианты, буквы, судья) → озвучка (или ваш `audio.mp3`) → паузы → сборка → замер тайминга.
5. **Проверка глазами обязательна** (скиллы `deep-audit`, `av-ground-truth-check`): кадры в `frames/`, `media_plan/frames_report.json` (статусы, что прочитано на кадре, оценки судьи), `media_plan/timing_verification.json`, сам `final.mp4`. «Отчёты чистые» ≠ «ролик хороший».
Финал — одна строка «Готово. Файл: [путь]».

## Кадр: как выбирается
- Один блок между `[pause]` = один кадр. `[pause]` ставить там, где меняется картинка — каждые 1-2 предложения (8-15 с).
- Планировщик на фразу пишет спецификацию старого образца (focus, core, subject, claims must/should) и рисунок: `scene` (без текста) / `caption` (одна подпись до 4 слов) / `diagram` (2-6 подписей), русские подписи дословно, английское описание без текста (для схемы — где пустые места и куда стрелки), герой, фон. Бриф автора `[shot:...]` главнее модели.
- **Буквы нейросеть не пишет никогда** (решение владельца 30.09): на «кадр с подписью» она оставляет пустую нижнюю полосу, на схеме — пустые места и стрелки к ним. Модель со зрением читает каждый вариант: на сыром кадре не должно быть ни одной буквы, псевдонадпись — брак.
- **Подписи кладёт код** (`scripts/labels.py`): Shantell Sans ExtraBold (жирный маркер «от руки»), если знака нет — Balsamiq Sans Bold; кегль подбирается под место, перенос по словам; обводки нет нигде, цвет по фону под подписью (чёрный на светлом, белый на тёмном). Место: пустая нижняя полоса для крупной подписи, иначе рамку возвращает модель со зрением. Пустота места проверяется по пикселям: замер 30.09 — пустой фон 0–0,4% «рисунка», любой рисунок в рамке 6,5–10,6%, порог 1,5%. На рисунок подпись не ставится: пробуется следующий годный вариант, не легла ни на один — кадр в брак.
- Сетка судьи → проверка лучших по утверждениям → вектор `claims_vector` → при ничьей `rank_look`. Не годен ни один — ещё раунд (`IMAGE_ROUNDS`). Не годен и после — `rejected`: на экран не идёт, время отдаётся соседнему проверенному кадру («ни карточек, ни повторов», решение владельца в старом генераторе).
- Промпт картинки: главное первым, стиль коротким хвостом в конце (урок старого `shot_generator`: длинный стиль впереди съедал предмет).

## Модель картинок — кандидаты (проверено 30.09 по карточкам моделей)
Ни одна модель не гарантирует «ноль артефактов» — гарантию даёт система: несколько вариантов, проверка «на кадре нет букв», судья, подписи кодом, брак на экран не идёт. Выбирать замером на 10-15 кадрах реального плана (`frame_generator.py --only ...`, доля `ok` в `frames_report.json`).
Русский текст модели больше не нужен (его пишет код) — модель выбирается по стилю, пониманию промпта и постоянству героя.
| модель | лицензия | размер | русский текст | зачем |
|---|---|---|---|---|
| **Kandinsky 5.0 Image Lite** (Сбер) | MIT (карточка HF) | 6B | обучена на 10M+ картинок с русским текстом, включая рукописный | главный кандидат на кириллицу; есть модель редактирования (I2I) для героя по образцу |
| **Qwen-Image-2512** (Alibaba) | Apache 2.0 | 20B | сильнейшая открытая по тексту, но документирована для EN/ZH | лучшее понимание промпта и стиля; Lightning — 4-8 шагов; Edit-2511 для героя по образцу |
| GLM-Image (Zhipu) | MIT | ~16B | отдельный кодировщик глифов, языки кроме EN/ZH не заявлены | запасной |
Не брать: Qwen-Image-2.0/2.1 — только некоммерческая лицензия.

## Деньги
Локальная модель картинок бесплатна. Платно: планировщик (DeepSeek, копейки), судья и чтение подписей (Qwen 3.7 Plus; потолок `SHOT_JUDGE_MAX_SPEND`), озвучка (`--tts`). Платная модель картинок (`IMAGE_BACKEND=gateway`) — только с `--confirm-spend` и потолком `IMAGE_MAX_SPEND`, цена печатается до вызова. Всё кэшируется: перезапуск не платит.

## Сценарий: стиль (из исходного CLAUDE.md)
- 5-12 слов, разговорно, на «ты». Без приветствий, «подпишись», канцелярита, «учёные доказали» без имени, паразитов («важно понимать» в любой форме).
- Живой стиль с первого черновика; анти-ИИ: одна риторическая форма («Не X. А Y», афоризм-пара, нумерованная тройка) не чаще двух раз за сценарий.
- Хук (90 с) — пять рычагов: узнавание себя, вопрос с ответом «да», контринтуитив, якорь-авторитет в первые 10 с, петля-обещание.
- Фактчек каждого имени, даты, числа; легенды — «по одной из версий».
- Теги TTS: `[energetic]` (хук, 1 раз), `[pause]`, `[short pause]`, `[slowly]`, `[emphasis]`. Нельзя: `[long pause]`, `[laugh]`, `[sigh]`, `[whisper]`.
- Формат: `=== METADATA ===` (TITLE:), `=== HOOK ===`, `=== BLOCK N: Название ===`, `=== FINAL ===`.

## Честные пределы
- **Живьём не проверено:** локальная модель картинок, судья и чтение подписей на рисованных кадрах, планировщик с новым описанием рисунка — в контейнере разработки нет ни видеокарты, ни ключей. Проверено тестами (подделки шлюза и модели) и сквозной сборкой на синтетике.
- **Судья откалиброван на документальной фотосъёмке** (эп.94 старого канала). На дудлах его пороги и вопросы не мерились — первый ролик размечать глазами и сравнить.
- **Шаблон ComfyUI** (`assets/comfyui/qwen_image_template_api.json`) составлен по стандартному графу и не запускался; надёжнее экспортировать свой.
- **Модель картинок выбирать замером** на 10-15 кадрах реального плана (доля кадров с верными буквами + судья), а не по обзорам.
- **Герой держится только описанием в промпте;** референс-картинка пока не подаётся (нужна модель/граф с редактированием по образцу).
- Тесты старого репозитория перенесены только для перенесённого кода (судья, разбор сценария, озвучка, паузы, звук, субтитры, замер тайминга).
