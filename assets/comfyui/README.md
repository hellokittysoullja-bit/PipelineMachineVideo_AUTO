# Локальная модель картинок через ComfyUI

Генератор кадров (`scripts/frame_generator.py`, `IMAGE_BACKEND=comfyui`) отправляет в ComfyUI граф
в API-формате и подставляет в него метки:

| метка | что подставляется |
|---|---|
| `{{PROMPT}}` | описание кадра + русские подписи + стиль канала |
| `{{NEGATIVE}}` | негатив (фото, 3D, водяной знак, ошибки в тексте) |
| `{{SEED}}` | зерно варианта (детерминировано: один кадр = одни и те же варианты) |
| `{{WIDTH}}`, `{{HEIGHT}}` | размер из `channel_profile.json` → `image.size` |

## Как получить свой граф (надёжнее шаблона)
1. Соберите в ComfyUI рабочий граф вашей модели и проверьте, что он рисует.
2. Впишите метки вместо текста промпта, негатива, seed и размера.
3. Menu → Export (API) → сохраните JSON, путь — в `.env`: `IMAGE_COMFY_WORKFLOW=...`.

`qwen_image_template_api.json` — шаблон по стандартному графу Qwen-Image для ComfyUI. Имена
файлов моделей в нём — как в официальном примере ComfyUI; **живьём в этом репозитории он не
запускался** (в контейнере разработки нет видеокарты). Если имена у вас другие, поправьте их или
экспортируйте свой граф.

Выбор модели — замером, а не по обзорам: 10-15 кадров из реального плана через каждую
модель-кандидата (`--only 1,2,3,...`), отчёт `media_plan/frames_report.json` показывает, у скольких
подписи прочитаны без ошибки и что сказал судья.
