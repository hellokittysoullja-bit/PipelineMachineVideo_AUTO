# Паспорт мира эпизода (`media_plan/world_card.json`)

Шаг 1 плана «искоренить неподходящие кадры на корневом уровне». Отвечает на
вопрос **«в каком мире живёт ЭТОТ эпизод»** — из его собственного текста, а
не из кода и не из настроек канала.

## Зачем — измеренная причина, не гипотеза

Разбор золотого набора опубликованного эпизода `01_ves-mecha` (17.09, 40
кадров с вердиктами, 17 из них брак):

| причина брака | сколько кадров |
|---|---|
| гейты забраковали САМИ, кадр всё равно в ролике | **8 из 17** |
| гейты пропустили (они этот класс не видят) | **9 из 17** |
| дал ОДИН запрос без якоря мира — `greatsword warrior fight` | **4** |
| дал запрос `medieval knight sword battle` (фестиваль с публикой) | 2 |
| кандидатов просмотрено на слот | **6.6** |

Отдельно: `milk bottle hand` дал 2 брака, хотя запрос был ПРАВИЛЬНЫЙ —
фраза диктора прямо просит современный пакет молока как меру веса. То есть
дело было не в бедности фотобанков, а выше по течению.

При этом «что в этом эпизоде уместно» жило в ПЯТИ местах, и главное из них
было литералом в коде:

```python
_QUERY_ERA_ANCHORS_DEFAULT = ("medieval", "knight", "armour", ... )  # 40 слов
```

`channel_profile.json` этого канала их даже не переопределял. Для эпизода
про психологию или неандертальцев этот список не «менее точен» — он про
другое, и ровно он подставлялся бы в каждый запрос к стоку. Уже измеренный
случай: бриф `a phone lying face down on a bedside table at night` уезжал в
сток как `medieval phone lying face down`. С каждым запросом.

## Что в паспорте

```json
{
  "schema_version": 1,
  "register": "historical | modern | abstract | scientific | mixed",
  "era": {"from": 1290, "to": 1480},
  "culture": {"include": ["english", "french"], "exclude": ["roman", "japanese"]},
  "must_not_show": ["sport fencing", "modern spectators at a reenactment"],
  "expected_subjects": ["plate armour", "churned wet mud"],
  "era_anchor_terms": ["medieval", "15th century", "plate armour"],
  "modern_props_allowed": true,
  "notes": "..."
}
```

**Годы — знаковые целые.** `-300000` значит 300000 год до н.э. Требование
владельца прямое: ниша может быть любой, в том числе доисторической. Строку
«XV век» нельзя сравнить с паспортом музейного предмета, знаковое число —
можно, той же `museum_sources.era_overlaps()`.

**Запреты — конкретные классы, а не «современность вообще».** У эпизода 02
в тексте есть НАСТОЯЩАЯ современная археология (братская могила Таутона,
раскопки 1996, судебная медицина Брэдфордского университета). Общий запрет
«никаких современных людей» убил бы законный кадр раскопок. Поэтому
запрещены `sport fencing`, `cosplay`, `modern spectators at a reenactment`,
`brand logo` — то, что видно на картинке и чего в этом эпизоде быть не
должно.

**Современная вещь бывает законной.** `modern_props_allowed` отмечает
эпизоды, которые сами используют современность как сравнение («весит как
пакет молока»). Разрешение при этом СЛОТОВОЕ, а не эпизодное: запрет
остаётся на эпизоде, а право показать современную вещь даёт бриф слота.
Читателя у поля пока нет сознательно — единственный законный читатель это
приёмка кадра, и accessor появится вместе с ней, а не заранее.

## Мозг сменяемый, харнесс общий

Модуль **не содержит ни одной словарной эвристики** — она была бы тем же
хардкодом, только этажом ниже. Он умеет собрать вопрос, проверить ответ и
отдать данные. Отвечает кто угодно:

```bash
python scripts/world_card.py videos/NN --prompt --niche "психология"   # вопрос
python scripts/world_card.py videos/NN --answer ответ.txt              # запись
python scripts/world_card.py videos/NN --check                         # проверка
```

Тот же приём, что уже закрыл разрыв у брифов кадра
(`shot_brief_director.py --brain packets/local/file`). По протоколу
(ЧАСТЬ 13, Шаг 2-3) сценарий пишет сессия Claude — она же и заполняет
паспорт, одним проходом, бесплатно.

## Кто уже читает паспорт

| потребитель | что меняется |
|---|---|
| `brief_to_stock_query()` | якорь мира в запросе к стокам |
| `_openverse_query_cascade()` | якорь, который обязан выжить в каскаде |
| `lint_authored_queries()` | ругается по миру эпизода, а не по словарю в коде |
| `filter_alt_blocklist()` | плюс чужие культуры эпизода (`culture.exclude`) |
| `_selection_stack_signature()` | смена паспорта инвалидирует кэш кандидатов |

## Замеры этой правки

На 142 брифах эпизода 02 (`videos/02_ne-mechom`, паспорт в репозитории):

* запросов к стоку изменилось **30 из 142**;
* запросов **без якоря мира: 0 из 142**;
* блоклист кандидатов **51 → 65 терминов**, добавлены чужие культуры
  ЭПИЗОДА: `roman`, `greek`, `viking`, `egyptian`, `japanese`, `chinese`,
  `indian`, `persian`, `turkish`, `ottoman`, `arab`, `mongol`, `javanese`,
  `mesoamerican`.

**Римские легионеры — реальный найденный кадр, а не пример.** В готовом
`videos/02_ne-mechom/final.mp4` на 14-й секунде стоят римские легионеры:
правильный континент, не то тысячелетие. Ни один гейт этого не видел —
домен-гвард спрашивает «европейский клинок или азиатский», и по этой оси Рим
европейский. Слово `roman` в блоклисте КАНАЛА отсутствовало и не должно было
там быть: для эпизода про Римскую империю это был бы запрет на предмет
разговора. Чужая культура — свойство эпизода, и теперь она приходит из
паспорта. Тест держит настоящий слаг Pexels
(`roman-soldiers-historical-reenactment-event-38103939`).

## Своя ошибка, найденная замером

Первая версия правки считала якоря по СЛОВАМ, а паспорт объявляет якорями и
фразы (`plate armour`, `manuscript illumination`) — двухсловный якорь не
совпадал ни с чем никогда. Следствие было не безобидным: бриф, уже
называющий эпоху, считался неякоренным и получал сверху лишний `medieval`,
вытесняя слово автора из лимита в пять слов. Замер на 142 брифах показал 17
таких молча изменённых запросов. Починено (фраза проверяется как фраза,
приписывается только ОДНОСЛОВНЫЙ якорь), закрыто тестом.

## Честные пределы

* Паспорт меняет, КТО попадает в пул, и **не решает, кто победит**.
  Оставшиеся 9 браков из 17 (те, что прошли все гейты) закрывает приёмка
  кадра — следующий шаг, он ещё не написан.
* Влияние на ГОТОВЫЕ кадры **не измерено**: замерены текст запросов и состав
  блоклиста. Честная проверка — полный рендер с ключами стоков и разметка
  владельца, а ключей стоков в контейнере нет.
* Паспорта эпизода 01 нет — он опубликован, перерендеривать его незачем.
* `shot_domain.anchor_words` (правило про «человека без привязки к эпохе» в
  режиссёре брифов) к паспорту **ещё не подключён** — там своя развилка, и
  трогать её в этом шаге значило бы менять две вещи разом.
