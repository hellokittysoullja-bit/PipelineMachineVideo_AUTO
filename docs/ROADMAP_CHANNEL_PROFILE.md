# План (не реализовано, отложено по решению пользователя): Профиль канала

Записано как план — реализация начнётся отдельно, по явному "делай".

## Проблема

Пайплайн (`pipeline_smart.py`, `generate_music_asset.py`) сейчас параметрирован
ПОД ОДИН канал (средневековое оружие, документалка): цветовой грейд
(`MOOD_GRADE`), музыкальный генератор (тихий процедурный дрон), контент-
блоклист (`CONTENT_ALT_BLOCKLIST` — исключает cosplay/anime, что верно для
документалки и НЕВЕРНО для канала про игры/Roblox), темп повествования —
всё зашито константами, не читается из конфига.

Пользователь хочет: дать пайплайну совсем другую тему (психология, детский
контент, Roblox) — и чтобы он адаптировался (звук, монтаж, цвет, контент-
фильтр), а не тянул к средневековой эстетике по умолчанию.

## Предлагаемое решение

1. **`channel_profile.json`** (новый файл рядом с CHANNEL.md) — тон, палитра
   грейда, темп, музыкальный "портрет", стиль подписей, разрешённый/
   запрещённый визуальный контент. У существующего канала — со ЗНАЧЕНИЯМИ
   ПО УМОЛЧАНИЮ = текущее поведение (ноль изменений без создания нового
   профиля).
2. **Цвет** — `film_look()`/`MOOD_GRADE` читают палитру из профиля вместо
   зашитых 3 грейдов.
3. **Музыка** — второй, архитектурно ДРУГОЙ генератор (не дрон, а
   ритм+перкуссия для энергичного/детского/игрового контента), выбор по
   профилю. Самая дорогая по коду часть.
4. **Контент-блоклист** — становится частью профиля, не глобальной
   константой (для игрового канала cosplay/anime — не баг, а нужный контент).
5. **Темп/ритм** — слов/мин, длина кадра, паузы — тоже из профиля.

## Риски

Большой рефакторинг, трогает грейд/музыку/блоклист/подбор фото/тайминг.
Полную уверенность даёт только реальный рендер на канале с ДРУГИМ
профилем — до этого момента проверка только юнит-уровня + regression на
существующем эпизоде (что средневековый канал не изменился).
