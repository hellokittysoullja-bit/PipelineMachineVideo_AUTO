# Архив замеров оркестратора v5 (26–27.09)

Всё, чем замерялся оркестратор кадров v5 за две сессии: планы и сырые ответы DeepSeek, ответы судьи на кадры,
слепые метки, итоги прогонов, журналы и код замеров. Выводы — в `docs/quality/ORCHESTRATOR_V5.md`, здесь — данные,
из которых они получены. Таблицы документа пересчитывает тест `tests/test_orchestrator_v5_archive.py`: без сети
и без денег, прод-функциями там, где решает код.

Если тест упал, значит, разошлись документ и данные. Или прод-логика решает иначе, чем на замере, и числа
документа описывают уже не текущий код. Это записывается, а не подгоняется.

## Что пересчитывает тест

- **4.1.** Оценка ожиданий — прод-функцией `orchestrator_bench.score`, по заданиям из отчётов. Сверяются:
  - v3 против v5 (прогон `v5n_all`, по нему написана таблица);
  - итог «3 фразы из 105 против 28»;
  - вторая выборка v3 на 59 фразах живого пула;
  - цена.

  Отдельно проверяется текст, который стоит в коде: правило запросов, прогон `v5o_all`. У него образа метафоры
  нет ни в главном, ни в запросах ни на одном наборе, главный предмет — 84 из 87.
- **4.2.** Ключ каждого из 631 спрошенного кадра считает ТЕКУЩАЯ прод-логика судьи (`claims_vector`,
  `nothing_met`) по сохранённым ответам Qwen. Он совпадает с ключом, записанным на замере. Из ключей
  пересчитываются по десяти дампам все столбцы таблицы:
  - годное и брак на экране;
  - второй круг;
  - брак, принятый проверкой, и годные, отклонённые миром;
  - верные пары;
  - среднее четырёх планов.
- **4.3.**
  - Сводные метки выводятся из исходных листов.
  - По ним считаются восемь рук: сумма, брак, лучший и годные в пятёрке, парные сравнения.
  - Приманки: 114 из 126 — прежней меткой.
  - Правила выбора из пятёрки на 285 кандидатах: 122 / 122 / 115 / 113 / 66.
- **4.5.**
  - Выбор сетки заново из её оценок, по правилу ничьих: 171 → 204.7, брак 77 → 51, 38 лучше и 11 хуже.
  - Цена: 61 599 на 194 сетки.
  - Маршрут по сходству и по типу чтения.
- **4.6.** Три способа отсечь брак DeepSeek-ом по тексту на 190 пятёрках: слова подписи, проверка подписей
  (с рассуждением и без), ловушки задания. Для каждого — сколько помечено и что стало с выбором правилом рендера.
  Рядом — сетка судьи на той же базе. Отдельно — что единственный плюс проверки подписей держится на одном плане.

## Как устроены данные

- **Ключ фразы** — `эпизод#номер` (`ep94_hook#0` — «Вот кинжал.»). Эпизоды и сценарии —
  `tests/fixtures/orchestrator_bench/`.
- **Метка кадра** — 0/1/2, слепая: кадры всех рук фразы лежат вперемешку на одном листе, без имени руки.
  - 2 — зритель принял бы кадр к этой фразе без вопросов;
  - 1 — проходной;
  - 0 — не тот предмет или мир, современное в историческом, текст в кадре.

  Метка переносится между прогонами по паре «фраза + кандидат».
- **Кандидат** — по номеру источника (`met:32684`, `commons:374410`, число — Pexels). Картинок в архиве нет.
  Превью достаётся по `probe_url` из `free_zone` (`runs → arms → head`), пока источник его отдаёт.
- **Руки** бесплатной зоны:
  - `v3N` / `v3R` / `v3R2` — план А прежнего вопроса в трёх процессах;
  - `v3N2` — вторая выборка того же вопроса;
  - `v5oN` — итоговое правило задания;
  - `v5pN` / `v5pN2` — «главное + состояние»;
  - `hybS` — гибрид.
- **Прогоны планировщика.** `v3_*` — прежний вопрос. `v5a…v5p` — редакции задания по порядку, `_all` — все
  восемь эпизодов, `_rep` / `_den` — повторы для разброса. `hyb*` — гибрид запросов.

## Честные пределы

- **Метки — Claude, а не владельца.** Все выводы о качестве кадров — глаза автора правки.
- **Черновая папка сессии не сохраняется.** Архив — то, что из неё отобрано. Не взяты:
  - картинки;
  - эмбеддинги и кэши отбора (`temp_smart`);
  - копии сценариев и паспортов (они в `tests/fixtures/orchestrator_bench/`);
  - читаемые выдачи планов (`shot_plan.txt`, их пишет код из плана);
  - журналы установки пакетов.
- **Ранние поколения бесплатной зоны (`M2`, `M4`, `M4c`) хранятся как история.** Их выводы сняты: первый прогон
  был несравним из-за троттлинга источников, а все сравнения шли против одной выборки плана (раздел 4.3). Тест их
  не сверяет.
- **Сквозной прогон (4.4) остановлен** и сравнения не дал.
