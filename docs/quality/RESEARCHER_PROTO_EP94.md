# Эпизод 94: где на самом деле ломается подбор (24.09)

## 1. Замер глубины пула: сортировка не виновата

Для шести фраз, где judge12/13 ставили слабый кадр или ничего, судья
(Qwen 3.7 Plus, сетка) оценил кандидатов с 21-го по 200-е место прод-каскада
(1037 кадров, 42 тыс. токенов баланса). Все 171 кадр с оценкой 2-3 просмотрены
глазами.

| фраза | лучшее на местах 21-200 | лучше первой двадцатки? |
|---|---|---|
| #2 кинжал на ладони | музейные кинжалы, руки держат кинжал | нет |
| #4 клинок в щель доспеха | кинжалы и пластины доспеха по отдельности | нет |
| #5 рыцарь падает в грязь | фестивали с толпой, стоящие рыцари | нет |
| #6 конница на пехоту | уланы, наполеоновские всадники, тбурида | нет |
| #7 не может подняться | шлемы, куски доспеха, фестиваль | нет |
| #8 стрела по нагруднику | пластины доспеха; стрелы нет нигде | нет |

Выводы:
- Нужного кадра нет в том, что приносит поиск. Копать глубже бесполезно.
- Сетка судьи на широком просмотре хвалит чужую эпоху почти всегда: из
  19 «троек» точных — ноль (уланы, тбурида, картина XVIII века). Расширять
  ей обзор значит тащить брак.

Пределы замера: только фото; места дальше 200-го (в пуле 650–1000) не
смотрелись; отбракованные судьёй кадры глазами не проверялись; разметка —
Claude, не владельца.

## 2. Прототип «исследователя» вручную

Для тех же фраз поиск по смыслу, с названием КОНКРЕТНЫХ известных
изображений и классов материала, которых в пуле нет вовсе: миниатюры
хроник XIV–XV вв., фехтовальные трактаты, надгробия, Wikimedia Commons
только «общественное достояние»/CC0 по метаданным файла (74 PD + 9 CC0,
атрибуция не требуется ни у одного).

Лист: `docs/refactor/sheets/ep94_researcher_proto.jpg` (judge13 против
лучшего найденного). Найдено по смыслу и эпохе на всех девяти фразах:
Азенкур (Сент-Олбанская хроника), Креси (Фруассар), Кодекс Валлерштайн
(бой в доспехах с клинками), трактат Тальхоффера (бой на кинжалах),
надгробие рыцаря (лежит, не встать), Венгерская хроника 1330 (дождь
стрел), «Эдуард III считает павших» (живые среди павших).

Почему пул этого не содержал:
- у пайплайна не было поиска по Wikimedia Commons напрямую;
- Openverse берётся только с меткой CC0, а миниатюры там помечены как
  «общественное достояние по возрасту»;
- запросы пишутся как стоковые (2-4 общих слова), а находит знание:
  «Battle of Agincourt St Albans Chronicle», «Froissart Crecy», «Talhoffer».

Видео со стоков для средневековых действий — почти сплошь мусор, и
половина провалов — многозначность слов: «knight fall» → осенние листья,
«armored combat» → бронепоезда и черепаха, «arrow armor» → значки-стрелки.

Честные пределы:
- выбор кадров — глазами Claude, автомат ещё должен повторить его сам;
- 7 кадров из 9 — рисунки; для кинематографичности нужен наезд на нужную
  деталь (а не на всю страницу) и баланс с фото и видео по эпизоду.

## 3. Что из этого следует для архитектуры

1. Источник Wikimedia Commons: только PD/CC0 по метаданным файла,
   `AttributionRequired` не `true`.
2. Мозг пишет запросы ЗНАНИЕМ: где историческое — называет известные
   изображения, рукописи, трактаты; для видео — однозначные слова.
3. Второй круг поиска, если ничего не прошло проверку: мозгу показывают,
   что нашлось и почему отклонено; результат сохраняется в план.
