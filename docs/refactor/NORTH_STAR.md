# Целевая архитектура подбора кадра

Цель: каждой фразе — кадр, который показывает ровно то, что сказано, в
верной эпохе и культуре, лучший по качеству среди равных по смыслу; в
любой нише, без слов о нише в коде.

## Главный принцип: ни один компонент не «потолок»

Любая модель (судья, мозг брифов, генератор, локальный ранжировщик) —
параметр за интерфейсом, а не решение, вшитое в код. Решение о том, какая
модель стоит по умолчанию, принимает **замер на размеченных данных**, и
замер остаётся, когда модели меняются. Так судья не может тихо стать
костылём: как только появится модель лучше, замер покажет это числом, и
смена — строка конфигурации.

Второе правило — удалять слой, который замер показал лишним. Каждая
эвристика (пороги косинуса, ловушки-негативы, блоклисты слов, якоря эпохи
словами, выбор вида медиа по словам действия, обрезка брифа до пяти слов)
была разумна, когда умной модели в контуре не было. Когда модель сильнее
на замере, эвристика перестаёт помогать и начинает мешать: она отсекает
годные кадры до того, как их увидит модель. Такие слои удаляются, а не
копятся.

## Конвейер

1. **Режиссёр** (текстовая модель, глава с контекстом): по каждой фразе —
   что показать, тип кадра, нужно ли движение, 2-3 запасные формулировки
   (от точной к более общей).
2. **Широкий охват**: музеи, архивы, стоки — по формулировкам режиссёра;
   **генерация кадра по брифу** — как ещё один источник того же пула.
3. **Каскад ранжирования**: дешёвая локальная модель по превью ВСЕГО пула
   (сотни кандидатов) → судье уходят лучшие, а не первые по очереди.
4. **Судья** (модель «зрение+язык»): сравнивает кандидатов слота на одной
   сетке — смысл, эпоха и культура, артефакты генерации; видео — лентой
   кадров. Сильная и дорогая модель — только на спорных слотах.
5. **Сборка эпизода**: ритм крупностей и чередование — ограниченная
   добавка, которая не перебивает смысл.
6. **Замер**: слепая разметка пулов владельцем по нишам + контактные листы
   до/после; он выбирает модели по умолчанию и удаляет лишние слои.

## Что уже измерено (эпизод 94, 9 фраз)

| | средняя оценка судьи (0-3) |
|---|---|
| только поиск (судья выбирает из найденного) | 1.44 |
| только генерация (FLUX.2 klein, бесплатно) | 2.11 |
| лучшее из двух по слоту | **2.44** |

Генерация выиграла 6 слотов из 9 (действия: «клинок в щель доспеха»,
«рыцарь в грязи», «не может подняться»), поиск — 3 (подлинные предметы:
«вот кинжал»). Выбор лучшего из двух по построению не ухудшает ни один
слот. Условия: лицензия FLUX.2 klein — Apache 2.0, картинки FLUX.1 dev
разрешены для коммерческого использования; водяного знака на выдаче нет
(проверено по углам); разрешение 1344x768 — ниже кадра 1080p, нужен
апскейл или платная модель с большим разрешением.

Найдено при этом замере: судья видит 18 кандидатов из ~600 в пуле, и эти
18 набраны по очереди из запросов, а не по качеству; кандидаты запроса
из брифа фразы в среднем не лучше общих (0.66 против 0.70) — рычаг не в
порядке запросов, а в ранжировании всего пула (п. 3).

Честные пределы: оценки судьи зависят от соседей по сетке (одно и то же
конное шоу получило 3 в сетке найденных и 2 в паре с генерацией), поэтому
сравнивать надо внутри слота на одной сетке; сгенерированный кадр может
ошибиться в деталях эпохи и анатомии, и это должен ловить судья; для
реалистичных сгенерированных сцен YouTube просит отметку о синтетическом
контенте при загрузке — решение владельца.
