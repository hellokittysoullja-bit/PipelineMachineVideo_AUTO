# Запуск на видеокарте (RTX 4090, RTX 6000 Ada)

Ветка `claude/generator_gpu`. Что именно изменено — в `CLAUDE.md`, раздел «Ветка под видеокарту».

**Модели зрения в этой ветке — только Qwen3-VL** (Embedding-8B и Reranker-2B, решение владельца 29.09). Им нужна видеокарта CUDA с памятью от 24 ГБ: сами модели занимают ~20 ГБ. На T4 (16 ГБ) ветка не работает, для неё есть CPU-ветка.

## 1. Окружение

```bash
git clone <адрес репозитория> && cd PipelineMachineVideo_AUTO
git checkout claude/generator_gpu
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
pip install torchvision   # та же версия CUDA, что у torch; нужна процессору Qwen3-VL
```

## 2. PyTorch с CUDA

```bash
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

Должно напечатать `True` и имя карты. Если `False` — поставить сборку torch с CUDA по команде с pytorch.org для своей версии CUDA.

## 3. ffmpeg с NVENC и drawtext

```bash
sudo apt-get update && sudo apt-get install -y ffmpeg
ffmpeg -hide_banner -encoders | grep nvenc      # должен быть hevc_nvenc
ffmpeg -hide_banner -filters | grep drawtext    # нужен для титров и плашек
```

Если в сборке ffmpeg нет NVENC, клипы кодируются прежним libx264 (`CLIP_ENCODER=auto` проверит это сам).

## 4. Ключи

Скопировать `config.example.env` в `.env` и вписать свои ключи. Файл `.env` остаётся на машине, где идёт рендер, — учитывайте это на арендованном сервере.

## 5. Калибровка порогов — ОБЯЗАТЕЛЬНА, один раз

```bash
python scripts/calibrate_vision.py            # 5–15 минут, веса (~20 ГБ) скачаются сами
```

Без этого шага рендер откажет ещё до первых платных вызовов и напечатает эту же команду. Пороги гейтов выставляются по золотому набору из git, по тому же правилу, что было у SigLIP2: ноль потерь годных и терпимых кадров. Итог печатается числами (сколько брака ловит каждая ось). Смена модели или её разрешения потребует калибровки заново — рендер скажет об этом сам.

Замер качества каскада против прежней SigLIP2 (только там, где лежит запись эпизода 94):

```bash
python scripts/cascade_model_eval.py --freeze temp_selection_freeze/94_dagger_test
```

## 6. Разовая подготовка ради скорости

1. **Зеркало карточек Мет** (один раз, ~2 часа, можно оставить на ночь; прерванная сборка продолжается с места обрыва):

   ```bash
   python scripts/museum_sources.py mirror-met            # окно эпохи канала
   python scripts/museum_sources.py mirror-met --refresh  # раз в месяц
   ```

   Без зеркала Мет — до 3000 запросов на эпизод при скорости 1–5 в секунду.

2. **Квота Pexels.** Бесплатный ключ — 200 запросов в час, а эпизод на 70 слотов делает больше. Когда отбор идёт минуты, а не часы, квота кончается посреди прогона, и поиск Pexels в оставшихся слотах сужается. Pexels бесплатно поднимает лимит по запросу через форму на сайте.

3. **Упреждающий отбор** ВЫКЛЮЧЕН по умолчанию (`SLOT_SPECULATE=0`) и включать его не рекомендуется:
   - он решает слоты впереди заранее, включая вопросы судье. Вопрос, который упреждение задало, а настоящий цикл не задал, оплачен впустую;
   - он делит с настоящим циклом квоты источников, и израсходованная им квота может поменять кучу настоящего слота.

   Упреждающий ПОИСК (`SLOT_PREFETCH=1`) включён и выбор не меняет.

4. **RTX 4090 и RTX 6000 Ada.**
   - **Сессии NVENC.** У GeForce (4090) драйвер держит не больше 8 одновременных сессий кодера на систему. У RTX 6000 Ada лимита сессий нет. Рендер считает сессии сам: свободной нет — клип кодируется x264. Если на машине кодирует что-то ещё, задайте `NVENC_MAX_SESSIONS` меньше 8.
   - **Декодер видеокарты** (`HW_DECODE=auto`) снимает с процессора декодирование клипов в финальной склейке — только для форматов, которые декодировались бит в бит как на процессоре.
   - **Память.** Веса: Qwen3-VL-Embedding-8B 15.2 ГиБ + Reranker-2B 4.0 ГиБ, плюс CLIP эстетики, модель глубины и сессии NVENC. Перед загрузкой рендер сверяет СВОБОДНУЮ видеопамять (веса + 2.5 ГиБ запаса) и при нехватке отказывает с числами — закройте другие программы на карте. Нехватку посреди прогона модель переживает повторами с паузами до ~17 с (сессии NVENC держат память, пока идёт клип); если нехватка стойкая, рендер останавливается перед следующим слотом, а не пропускает кадры без проверки, и перезапуск продолжает с кэша. На RTX 6000 Ada (48 ГБ) места хватает с запасом.
   - **Что остаётся на процессоре.** Фильтры клипа (наезд, грейд, зерно) и финальное кодирование x264 medium: перенос на видеокарту менял бы сами пиксели или давал худшее качество на тот же размер.

## 7. Запуск

Как обычно: `python scripts/render_episode.py videos/NN_название`. В начале лога появится строка:

```
Устройство моделей: cuda (NVIDIA GeForce RTX 4090); зрение: Qwen/Qwen3-VL-Embedding-8B + Qwen/Qwen3-VL-Reranker-2B; кодер клипов: nvenc
```

## Честные пределы

- **Качество Qwen против SigLIP2 не измерено:** в среде, где писалась ветка, видеокарты нет. Первые числа дадут шаг 5 и `cascade_model_eval.py`.
- **Кэши.** Ключи кэшей и подпись отбора включают модель: первый прогон заново посчитает каскад и заново выберет кадры. Ответы судьи берутся из его кэша.
- **Полка** (`shelf_index.py`), собранная SigLIP2, не читается — её нужно пересобрать.
