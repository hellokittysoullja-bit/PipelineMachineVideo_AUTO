# Переносимость на другие ниши: правила канала — только для мира канала (02.10)

## Одно правило

`world_card.matches_channel(card, profile)` — совпадает ли мир эпизода с миром,
под который написаны правила канала. Совпадает (всё как раньше):

* паспорта нет;
* канал не объявил эпоху в профиле (`era_from`/`era_to`) — у клона правила профиля и есть его мир;
* эпизод про прошлое (`world_card.is_historical`), окно эпохи паспорта пересекается
  с окном канала, а среди своих культур (`culture.include`) есть хоть одна не чужая
  для канала. «Чужая» берётся из `foreign_culture_terms` профиля, тем же списком
  пользуется паспорт музейного предмета.

Иначе мир другой: современный, научный или абстрактный эпизод, эпоха вне окна,
или все свои культуры эпизода для канала чужие (Япония). Тогда правила канала
не применяются, действует только паспорт (`must_not_show`, `culture.exclude`,
`era_anchor_terms`, `expected_subjects`).

В пайплайне правило вызывается в одном месте — `pipeline_smart.episode_matches_channel()`.
Режиссёр главы вызывает его через `shot_planner_llm.episode_world()`.

## Что не может быть чистым плюсом

1. **Хэш КОДА отбора (`selection_code_signature`) меняется** — aa8e36cd… -> c16316b8…;
   подпись судьи прежняя (09e29df1…). Так устроен М6: подпись хэширует текст всего
   кода, достижимого от адаптеров, и любая правка этого кода её меняет. Значения в
   подписях (блоклист, ловушки, гварды, паспорт, стек) для эпизодов мира канала
   те же байты, строка `world:other` добавляется только эпизоду другого мира.
   Цена: первый рендер после слияния заново выберет кадры по кэшу кандидатов.
   Ответы судьи кэшируются по байтам картинки, спецификации — по тексту, поэтому
   платных повторов почти не будет. Обойти это можно только выносом логики из-под
   подписи, а это ровно то, против чего М6 заведён. Ту же цену несёт любая
   параллельная правка отбора.
2. **Цепочка моделей паспорта не расширена.** `world_card.generate` уже спрашивает
   две модели по очереди (`AUTO_MODELS`: Gemini 3.1 Pro, затем 3.6 Flash), и каждый
   вызов `gw.chat` сам повторяет попытки на сеть, 5xx и паузы шлюза. Добавить
   DeepSeek и Qwen из `text_chain` — значит в средневековом эпизоде, где обе Gemini
   упали, получить паспорт незамеренного качества вместо мира канала. Для этого
   канала это изменение поведения без замера (Gemini выбраны замером на шести
   ручных паспортах). Решение за владельцем; вместо этого — громкое предупреждение.
3. **«Нейтральных универсальных» ловушек и терминов блоклиста в другом мире нет.**
   Ни один термин канала не универсален: cosplay и anime — контент игрового канала,
   «modern kitchen» — контент психологии. Универсальный список без размеченной
   выдачи другой ниши был бы догадкой.
4. **Словарь движения в другом мире пуст целиком**, вместе с нейтральным
   «бежит -> running». Он откалиброван живой выдачей под мир канала; что из него
   переносится, не замерено. Касается только запросов без спецификации кадра:
   к запросам спецификации слова движения не приписываются никогда.
5. **Порядок в рендере.** `fill_briefs` (план локального режиссёра) идёт до
   `auto_plan_episode`. На самом первом рендере эпизода, когда паспорт ещё не
   составлен, заявки режиссёра проверяются по миру канала. Перенос шага поменял
   бы блоки, по которым он работает (до нарезки или после), поэтому не тронут.
6. Пункты 9–10 (грейд, пороги эмбеддинг-гейтов) — см. таблицу.
