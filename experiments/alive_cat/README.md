# Кодовое слово: «ЖИВОЙ КОТ»

Услышав его, открыть этот файл и продолжить отсюда. Опыт 06.10, бесплатный, на старых кадрах (ep2 + 01_sdvg_pismo).

## Что проверено

**Вырезание кота (BiRefNet через rembg, `cut.py`)** — 8 кадров, рамка кота от судьи (`boxes.json`, для 06/07/09/10 размечена вручную).
- Кот стоит отдельно (01, 02, 06, 10): вырезка отличная — мех, усы, пламя, дымок.
- Кот держит/касается предмета (05 стол, 07 мозг, 09 письмо): вырезается вместе с предметом.
- ISNet-anime хуже: полупрозрачный хвост, куски предметов.
- ~35 с на кадр на CPU; ONNX-сессия течёт по памяти (14 ГБ на втором кадре) — один кадр на процесс.

**Дорисовка фона (LaMa ONNX `Carve/LaMa-ONNX/lama_fp32.onnx`, `inpaint.py`)** — ~3 с на кадр.
- Чисто при небольшом коте (01, 02, 06, 10).
- Кот на полкадра (09): фон превращается в туман.
- Свечение пламени вне маски оставляет оранжевое пятно (04, 05) — маску расширять на свечение.
- Тень кота остаётся на фоне: если кот уходит, стирать и её.

**Remotion (`remotion/`)** — сцена 6 с: присед, прыжок пружиной, сжатие тени, дыхание, наклон к письму, наезд камеры, слово от руки. Рендер 29 с на 4 ядрах, headless shell из `/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`. Качество даёт слой кота поверх чистого фона, Remotion — только удобство анимации. Лицензия бесплатна до 3 сотрудников.

Листы: `sheet_masks_a.jpg` (исходник / BiRefNet / ISNet), `sheet_lama.jpg` (фон без кота).

## Что предложено, решения владельца ещё нет
1. Правило генерации для оживляемых кадров: кот стоит отдельно, с зазором до предметов.
2. Встроить вырезание + дорисовку фона в генератор (маска с запасом на свечение и тень).
3. Гибрид: подготовка в Python, сборка анимированных сцен в Remotion; старую сборку не убирать, пока новая не догонит по проверкам.
4. Следующий слой — моргание/голова: один дополнительный кадр с закрытыми глазами на сцену.

## Второй заход (06.10, всё на CPU, бесплатно)

`alive.py` — один ролик 6 с: параллакс по карте глубины + наклон головы + дёрганье уха + огонёк + дыхание. Рендер 2.5 мин на 6 с (numpy, не оптимизировано).
- **Карта глубины:** Depth-Anything-V2-**Small** ONNX (`onnx-community/depth-anything-v2-small`, Apache-2.0), ~1 с на кадр. Base/Large — некоммерческая лицензия, НЕ брать. Глубина считается по чистому фону (после LaMa), кот — плоская карточка в точке фокуса: разрывов фона нет, потому что за котом уже дорисовано.
- **Сетка (puppet warp):** поворот с весом — голова выше шеи (точка шеи, ось уха заданы вручную для кадра 10; для конвейера их даёт рамка головы судьи + верхние точки маски). Смаза меха при 3° и 9° (ухо) не видно.
- **Огонёк / дыхание:** работают.
- **Моргание — НЕ решено.** Четыре попытки: плоская заливка (наклейка), LaMa (возвращает зелёную радужку), мех-донор со лба (на маленькой голове попадает ухо). FLUX.2 Klein через шлюз (бесплатно) референс НЕ правит — рисует другого кота (полоски, нет загнутого уха). Путь: платная правка (Nano Banana — модель правки) или закрытые глаза при генерации кадра.

**n8n + FFmpeg:** ролик через n8n побайтно совпал с прямым ffmpeg (md5 и 288/288 кадров). Качества не даёт; полезен только как «клей» (расписание, Telegram, загрузка на YouTube). Лицензия Sustainable Use — для своего канала можно. Воркфлоу: `n8n_wf.json`.

## Кукла Чирка (06.10, CPU, бесплатно) — `doll/`
Из эталона `look/hero.png` (анфас) кодом нарезаны части: маска кота (BiRefNet), **мех без глаз** (LaMa — сработала, потому что маска глаза взята с обводкой +6 px и пиксели под маской обнулены), **радужка без зрачка** (средний зелёный + акварельный шум), **зрачок-спрайт** (только связные куски в центре радужки — иначе в маску попадает обводка и ездит вместе со зрачком).
Сцена 8 с (`doll.py`): взгляд влево/вправо (сдвиг зрачков), **моргание работает** (глаз сжимается к линии века, закрытый — дуга туши), наклон головы, дёрганье уха, взмах хвоста, огонёк, дыхание. Рендер ~5 мин на 8 с (numpy, не оптимизировано).
Ограничение: только эта поза (анфас, сидит). Действия (тянет, падает) остаются за генератором — гибрид.
Следующее бесплатно: рот кодом (линия туши → «о»/открытый) по разметке озвучки.

### Автоматика куклы и лапы (07.10) — `doll/doll_rig.py`, `doll/rig.json`
- Риг описан в `rig.json` (точки шеи, уха, хвоста, огонька, лап — один раз на персонажа). Фон жизни сам по зерну: моргание каждые 2.5–5.5 с (иногда двойное), ухо каждые 6–11 с, «оглядывание», хвост, дыхание, огонёк. Действия списком: `look` (x,y), `tilt` (градусы), `blink`.
- Рендер: OpenCV remap, повороты только в области части, по 1 потоку на процесс, 4 процесса. **Замер: 9 с ролика за ~40 с (≈4.5 с на секунду ролика)**; сами кадры ~2.2 с на секунду, остальное — апскейл до 1920 и x264 medium. Один кадр в одном процессе — 0.077 с.
- **Лапы ОТКЛОНЕНЫ (брак, `paw_zoom.jpg`).** (1) Отрезать переднюю лапу и дорисовать тело LaMa — на месте лапы белёсое пятно без контура живота: контур, которого никто не рисовал, нейросеть не придумывает. (2) Изгиб лапы сеткой: «показать» — тёмный смаз между передними лапами (соседняя тянется), «постучать» — лапа сплющивается, гнётся контур задней. Код `tap`/`point` оставлен в риге, но не использовать. Путь к лапам — нарисованные отдельно части (тело с поджатыми лапами + лапа отдельно), то есть платный набор частей.

### Лапа «машет» — платная правка, навсегда (07.10)
- `doll/gen_wave.py`: одна правка эталона в той же модели, что рисовала эталон (`ag/gemini-3.1-flash-image`, 1536x1024, medium) — **150 000 токенов, разрешено владельцем**. Результат `assets/hero_wave_raw.png`: лапа поднята, остальное совпадает с эталоном почти попиксельно (сдвиг головы 0.02 px, разница только в области руки).
- Дефект модели: внизу осталась и опущенная передняя ступня (три передние лапы). Исправлено бесплатно `doll/fixfoot.py`: ступня убрана, мех — LaMa, рыжее пятно (галлюцинация подушечки) убрано, контур живота — штрих туши с дрожанием пера. Итог `assets/hero_wave.png`, маска `assets/hero_wave_mask.png`.
- В риге (`rig.json` → `wave`): лапа — отдельный слой (всё, что вне силуэта эталона), машет изгибом ±12° от плеча. Подъём — смена позы рывком на 35% подъёма + доворот с −25° с отскоком (большой поворот изгибом растягивал лапу в «палку» — отклонено). Действие `{"do":"wave","n":3}`.
- Рендер с лапой: 8.5 с за 26.5 с (≈3.1 с на секунду ролика).
- **ВЕРДИКТ ВЛАДЕЛЬЦА (07.10): «машет» — ОТКЛОНЕНО, «кот так лапой не двигает, физически невозможно, выглядит ужасно».** Причины: модель вывела лапу из бока на уровне груди, как человеческую руку (у кота передняя лапа растёт из-под груди); движение — поворот всей руки от плеча, как дворник, а кошка двигает лапой в запястье. Действие `wave` не использовать. Картинку `assets/hero_wave*.png` для движения не применять.

### Лапа у груди — правильная анатомия (07.10), ПРИНЯТО к показу владельцу
- `doll/gen_paw_up.py`: вторая платная правка эталона (150 000 токенов, в пределах разрешённых 600k): лапа растёт из-под груди, локоть прижат, кисть согнута в запястье, под подбородком; на полу ОДНА передняя ступня, на месте поднятой нарисован контур живота (модель сделала это сама, без доработки). `assets/hero_paw_up.png`. Совпадение с эталоном: сдвиг головы 0.02 px, разница только в столбце лапы.
- Проверка: глазами + судья `qwen/qwen3.7-plus` по пунктам (2 передние, 2 задние, поза возможна, дефектов нет; замечание — лапа близко ко рту, читается как «задумался»).
- Маска позы — без BiRefNet (он съедает ~14 ГБ и уронил контейнер): маска эталона + пересчёт по белой бумаге только в столбце лапы, с запасом (иначе по краю области проступала рамка). `assets/hero_paw_up_mask.png`.
- В риге: поза `poses.paw_up`, действие `{"do":"paw","dur":...}`. Смена позы МГНОВЕННАЯ (растворение за 2 кадра давало полупрозрачного «призрака» ступни), перед ней присед-замах 0.15 с. Глаза/взгляд/моргание/голова/ухо/хвост/огонёк работают и в этой позе. Рендер 8 с — 15 с.
