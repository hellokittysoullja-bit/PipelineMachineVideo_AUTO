# Кодовое слово: «ЖИВОЙ КОТ»

Услышав его, открыть этот файл и продолжить отсюда. Опыт 06.10, бесплатный, на старых кадрах (ep2 + 01_sdvg_pismo).

## Что проверено

**Вырезание кота (BiRefNet через rembg, `cut.py`)** — 8 кадров, рамка кота от судьи (`boxes.json`, для 06/07/09/10 размечена вручную).
- Кот стоит отдельно (01, 02, 06, 10): вырезка отличная — мех, усы, пламя, дымок.
- Кот держит/касается предмета (05 стол, 07 мозг, 09 письмо): вырезается вместе с предметом.
- ISNet-anime хуже: полупрозрачный хвост, куски предметов.
- ~35 с на кадр на CPU; ONNX-сессия течёт по памяти (14 ГБ на втором кадре) — один кадр на процесс.

**Дорисовка фона (LaMa ONNX `Carve/LaMa-ONNX/lama_fp32.onnx`, `inpaint.py`)** — ~3 с на кадр.
- Чисто при небольшом коте (01, 02, 06, 10).
- Кот на полкадра (09): фон превращается в туман.
- Свечение пламени вне маски оставляет оранжевое пятно (04, 05) — маску расширять на свечение.
- Тень кота остаётся на фоне: если кот уходит, стирать и её.

**Remotion (`remotion/`)** — сцена 6 с: присед, прыжок пружиной, сжатие тени, дыхание, наклон к письму, наезд камеры, слово от руки. Рендер 29 с на 4 ядрах, headless shell из `/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`. Качество даёт слой кота поверх чистого фона, Remotion — только удобство анимации. Лицензия бесплатна до 3 сотрудников.

Листы: `sheet_masks_a.jpg` (исходник / BiRefNet / ISNet), `sheet_lama.jpg` (фон без кота).
